**Neon Tide City** — an original open-world crime game that runs entirely in the browser. Explore Port Solana, a fictional tropical harbor city, on foot or by car: steal cars, dodge a 0–5 star police wanted system, fight, earn cash, and work through a five-mission story arc for nightclub owner Vera Solano, plus taxi fares and a day/night cycle. Built with three.js; all art, music and sound are procedural and original. Progress saves to localStorage.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 in desktop Chrome
```
